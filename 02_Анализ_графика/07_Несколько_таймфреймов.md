# Урок 7. Анализ на нескольких таймфреймах

Схема «сверху вниз»:
1. **1W / 1D** — какой главный тренд? Где главные уровни?
2. **4H** — где цена сейчас относительно уровней? Есть ли сетап?
3. **1H** (по желанию) — точный момент входа.

## Правило
Сделка только по направлению старшего таймфрейма.
1D растёт, а на 4H откат к поддержке — ищем покупку.
1D падает — покупки не ищем, даже если на 4H «красиво».

## Минимальный набор для старта
Таймфреймы 1D + 4H, EMA 50 и 200, RSI 14, уровни, объём. Больше — мешает.
