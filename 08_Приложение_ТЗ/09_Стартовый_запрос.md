# Стартовый запрос для разработки

Скопируйте текст ниже и отправьте модели в Claude Code вместе с папкой «Трейдинг_с_нуля».

---

Ты разрабатываешь учебное приложение «Трейдинг с нуля» для обучения криптотрейдингу.
В папке «Трейдинг_с_нуля» лежит всё: контент уроков (папки 01–07) и техническое задание (папка 08).

Порядок работы:
1. Прочитай README.md и все файлы папки 08_Приложение_ТЗ. Если что-то в ТЗ противоречит
   друг другу или неясно — сначала задай вопросы, не додумывай.
2. Создай проект по `05_Платформа_и_технологии.md` (React + TypeScript + Vite, PWA).
3. Перенеси контент: уроки из Markdown, тесты из файлов `Тест.md` в JSON по формату
   из `06_Формат_заданий.md`.
4. Сделай **только версию 1** из `04_Этапы_разработки.md`: главная, ступень 01 полностью,
   калькулятор риска, справочник. Дизайн — по `08_Дизайн.md`.
5. Проверь: приложение запускается, работает на ширине 360px и на компьютере,
   в светлой и тёмной теме, прогресс сохраняется после перезагрузки,
   калькулятор считает по формуле из `03_Риск_менеджмент/04_Размер_позиции.md`.
6. Покажи результат и кратко опиши, что сделано и что дальше. Следующую версию
   начинай только после моего подтверждения.

Требования: интерфейс полностью на русском; без регистрации и сервера; данные на устройстве;
никаких реальных торговых функций и подключения к бирже.
