# Формат заданий и тестов

## Главный принцип
Задания проверяют **навыки, у которых есть правильный ответ**, а не угадывание направления цены.
Правильный ответ всегда объясняется.

## Типы заданий
| Тип | Что делает пользователь | Как проверяется |
|---|---|---|
| Вопрос с вариантами | Выбирает ответ | Сравнение с правильным, показ объяснения |
| Отметить уровень | Тапает или проводит зону на графике | Попадание в допустимую зону (задаётся в данных задания) |
| Поставить стоп | Ставит линию стопа для описанного входа | Стоп в допустимом диапазоне, объяснение почему |
| Определить тренд | Выбирает: восходящий, нисходящий, боковик | Сравнение с разметкой |
| Расчёт | Вводит число (размер позиции, R:R) | Сравнение с допуском ±1% |
| Задание на демосчёте | Отмечает галочку «выполнено» | Самопроверка, запись в журнал |

## Тренажёр (ступень 04 и позже)
Вопрос «куда пойдёт цена» допускается только в тренажёре. Оценивается **не угадывание**,
а соблюдение правил стратегии: был ли сетап, правильно ли стоит стоп, R:R не меньше 1:2.

## Пример задания в JSON
```json
{
  "id": "02-02-level-1",
  "type": "mark_zone",
  "lesson": "02_Анализ_графика/02_Уровни",
  "question": "Отметьте зону поддержки",
  "chart": "btc_1d_2023_q1",
  "answer": { "low": 21500, "high": 22300 },
  "tolerance": 0.01,
  "explanation": "Цена трижды останавливала падение в этой зоне."
}
```

## Тесты
- Вопросы хранятся в JSON по ступеням; ответы из файлов `Тест.md` переносятся в поле `answer`.
- Порядок вопросов и вариантов перемешивается.
- Порог прохождения 80%, пересдача без ограничений.
