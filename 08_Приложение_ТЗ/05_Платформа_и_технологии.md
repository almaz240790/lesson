# Платформа и технологии

## Где работает
Телефон (Android, iPhone), планшет, компьютер. **Один код для всех устройств.**

## Подход
1. **Сначала веб-приложение (PWA).** Открывается в браузере на любом устройстве, его можно
   «установить» на главный экран телефона, работает без интернета после первой загрузки.
2. **Потом магазины.** Тот же код упаковывается для Google Play и App Store через Capacitor.

## Рекомендуемый стек
| Задача | Технология |
|---|---|
| Интерфейс | React + TypeScript, сборка Vite |
| PWA и офлайн | vite-plugin-pwa |
| Мобильные сборки | Capacitor (Android, iOS) |
| Графики свечей | lightweight-charts (TradingView, открытая библиотека) |
| Хранение данных на устройстве | IndexedDB (через Dexie) |
| Контент уроков | Markdown-файлы из папок 01–07, тесты и задания — JSON |
| Стили | CSS-переменные для светлой и тёмной темы |

## Требования
- Интерфейс полностью на русском.
- Адаптивность: от экрана телефона 360px до широкого монитора.
- Работа без интернета: уроки, тесты, журнал, калькулятор.
- Данные пользователя хранятся на устройстве. Кнопка экспорта и импорта (JSON-файл),
  чтобы перенести прогресс и журнал на другое устройство.
- Регистрация и сервер в первых версиях **не нужны**.
