# Экраны

1. **Главная:** кнопка «Продолжить обучение», текущий урок, прогресс по ступеням, статистика журнала за неделю.
2. **Список ступеней:** 6 ступеней, закрытые — с замком.
3. **Урок:** текст, картинки графиков, кнопка «Урок пройден».
4. **Практика:** список заданий-галочек для демосчёта.
5. **Тест:** вопросы с вариантами ответа, результат, разбор ошибок.
6. **Журнал:** список сделок, кнопка «Добавить сделку» (сначала чек-лист).
7. **Статистика:** винрейт, итог в R, % соблюдения правил, просадка, разбивка по стратегиям.
8. **Калькулятор риска:** депозит, риск %, вход, стоп → размер позиции, R:R.
9. **Справочник:** поиск по глоссарию.
10. **Допуск:** чек-лист критериев перехода на реальные деньги с автоматической проверкой.
