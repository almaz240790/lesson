# Чек-лист перед сделкой

Любой ответ «нет» — сделки нет.

- [ ] Тренд на старшем таймфрейме (1D) за меня?
- [ ] Это сетап из моей стратегии, а не «просто кажется»?
- [ ] Стоп стоит там, где идея становится неверной?
- [ ] R:R не меньше 1:2?
- [ ] Риск не больше 1–2% депозита, размер посчитан по формуле?
- [ ] Дневной лимит потерь не достигнут?
- [ ] Я спокоен, не пытаюсь отыграться?
- [ ] Сделка записана в журнал с причиной входа?
