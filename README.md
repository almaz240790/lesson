# Трейдинг с нуля: криптовалюта

Пошаговая программа обучения: от полного нуля до своей торговой системы.
Практика ведётся на демосчёте биржи, без реальных денег.

## Как проходить
1. Идите строго по папкам по порядку: 01 → 02 → … → 06.
2. В каждой папке: сначала уроки по номерам, потом `Практика.md`, потом `Тест.md`.
3. Следующую папку открывайте, только если тест сдан минимум на 80% и практика выполнена.
4. Все сделки на демо записывайте в журнал (`06_Своя_система/02_Журнал_сделок_шаблон.md`).
5. Папка `07_Справочник` нужна всегда: глоссарий, шпаргалки, чек-лист.
6. Папка `08_Приложение_ТЗ` описывает, как превратить эту программу в приложение.
7. Папка `09_Уровень_профи` — для тех, кто уже торгует по своей системе и ведёт журнал. Её можно проходить отдельно от ступеней 01–06.

## Структура
```
01_Основы             — биржа, ордера, комиссии, свечи, таймфреймы
02_Анализ_графика     — тренд, уровни, объём, индикаторы, несколько таймфреймов
03_Риск_менеджмент    — риск на сделку, стоп, размер позиции, плечо
04_Стратегии          — 5 стратегий от простой к сложной
05_Психология         — эмоции, ошибки новичков, дисциплина
06_Своя_система       — торговый план, журнал, критерии перехода на реальные деньги
07_Справочник         — глоссарий, таймфреймы и индикаторы, чек-лист перед сделкой
08_Приложение_ТЗ      — техническое задание для приложения
09_Уровень_профи      — следующий уровень: статистика системы, бэктест, просадка, деривативы, портфель, процесс
```

## Сколько времени
При 30–60 минутах в день: основы и анализ — 3–4 недели, риск — 1 неделя,
стратегии — 2–3 месяца практики, своя система — от 1–2 месяцев.
Это нормально. Быстрых путей нет.

## Важно
Большинство начинающих трейдеров теряют деньги. Эта программа не гарантирует
прибыль. Реальные деньги — только после выполнения критериев из папки 06
и только сумма, которую не жалко потерять. Это учебный материал, а не финансовая консультация.
